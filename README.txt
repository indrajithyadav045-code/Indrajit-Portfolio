## Run Locally

This repository contains a static website. If the project uses plain HTML, CSS, and JavaScript:

1. Clone the repository:

   ```bash
   git clone https://github.com/indrajithyadav045-code/Indrajit-Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Indrajit-Portfolio
   ```

3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No Node.js installation is required for a plain static HTML website.
